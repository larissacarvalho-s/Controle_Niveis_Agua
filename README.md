## 📚 Sobre o projeto

Este projeto foi desenvolvido como atividade da Agenda 11 – Bibliotecas, da disciplina Desenvolvimento de Sistemas I, do curso Técnico em Desenvolvimento de Sistemas.

O programa simula o monitoramento de um reservatório de água, exibindo mensagens coloridas no terminal de acordo com o nível de água.

## 🎯 Objetivo

Utilizar a biblioteca Colorama para identificar visualmente os níveis de água de um reservatório, aplicando listas, funções e bibliotecas em Python.

## 🚦 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | 🔴 Vermelho |
| 2 | Baixo | 🟡 Amarelo |
| 3 | Médio | 🟢 Verde |
| 4 | Alto | 🩵 Ciano |
| 5 | Muito alto (alerta) | 🔵 Azul |

## 🛠️ Tecnologias utilizadas

- Python
- Biblioteca Colorama
- Visual Studio Code

## ⚙️ Como executar o projeto

### 1. Instalar a biblioteca

No terminal do VS Code, execute:

```bash
python -m pip install colorama
```

### 2. Executar o programa

Na pasta do projeto, execute:

```bash
python controle_agua.py
```

### 3. Conferir o resultado

O programa exibirá os cinco níveis do reservatório no terminal, cada um com sua cor correspondente.
